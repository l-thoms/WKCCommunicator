# WKC Communicator

[English](./README.md)

基于 BLE 通信，用于控制 WKC 系列设备，使用 .NET MAUI 编写。只支持安卓手机。

## 功能

* 使用方向键控制设备
* 修改设备部分基本设置

## 使用提醒

* 考虑到手机端操作的便捷性，通信协议未使用 BLE 原生配对方法。
